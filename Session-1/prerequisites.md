## Objectives
By the end of this session, you will be able to:
* Install Node.js and npm (if not already installed)
* Install TypeScript globally
* Initialize a TypeScript configuration file (`tsconfig.json`)
* Compile and run your first TypeScript file

---

## Step 1: Check Prerequisites

***first we need vscode and we need to use the terminal inside it***

TypeScript requires **Node.js** and **npm** (Node Package Manager).

Open your terminal and verify they are installed:

```bash
node -v
npm -v
```

if not we will need to install them 

-> Node.js download website: https://nodejs.org/en/download

Download toturial: https://youtu.be/lt5D2EWZMN0?si=PtSCGpQK9hP9l3Ma

**Note: don't forget to make sure that the version of nodejs is compatinle with your OS**

## Step 2: Install typescript 

**to install typescript globally on your system rum the following command: 



```bash
npm install -g typescript
```

-> verify the installation

```bash
tsc -v
```

## Step 3: Initialize the project 

inside your folder directory

```bash
tsc --init
```

-> to run your code 

```bash
tsc filename.ts
```

-> run the compiled Js file

```bash
node filename.js
```
