# Session 1: The First Island


---

## 📖 The Scenario

> After three days of storms, Sindbad's ship finally reaches land — not Atlantis, just the first island on the way there. His crew steps ashore: Elsiny the Navigator, Alshafei the Guardian, Omnia the Scholar, Omar the Warrior, and Adel the Archer.
>
> A stone gate blocks the only path forward. Ancient glowing letters appear across it:
>
> *"Only those who speak the old tongue may pass."*
>
> Omnia studies the writing and sighs. "It doesn't understand plain speech anymore. It only listens to... TypeScript."
>
> Five quick trials stand between the crew and the road ahead. Fail, and the gate stays shut.

---

## 🛠️ The Task

1️⃣ **Open the gate**
Initialize a TypeScript project, create a `tsconfig.json`, add one `.ts` file, and get it compiling and running.

2️⃣ **The treasure vault**
Declare one variable each of type `string`, `number`, `boolean`, and `any`. Then create an array holding a few treasure names.

3️⃣ **The crew manifest**
Create an interface `Sailor` with `name`, `role`, and `age`. Create one sailor object using it, and print one property from that object.

4️⃣ **Sindbad's command**
Write a function that accepts a sailor's name (`string`) and returns a blessing (`string`). Both the parameter and return type must be explicit.

5️⃣ **The final seal**
Create a `Promise` that resolves if the crew is accepted, or rejects otherwise. Handle both outcomes using `async`, `await`, and `try`/`catch`.
