# 📤 How to Submit Your Task

Follow these steps in order to submit your solution correctly.

---

## Steps

1️⃣ **Fork** our repository to your own GitHub account.

2️⃣ On your laptop, create a file named:
   `task_solution.ts`

3️⃣ Solve the task inside that file.

4️⃣ Upload the file to GitHub directly from your **browser** — you do **not** need to clone the repo.

5️⃣ Upload it into the **same task folder** that belongs to that session (not the repo root, not a random folder).

6️⃣ To let us know you've submitted, go back to our repository and open an **issue**:
   - **Title:** `YourName_id_sessionNumber`
   - **Body:** paste a **direct link** to your solution file (not just a link to your repo's homepage) — we should be able to click it and land straight on your solution.

---

## **NOTES:** 

* the fork is **only done once** other steps are done for each task.
<br>
* Submissions **that don't meet these points** (wrong folder, indirect link, or messy/unmatched steps) **will need to be resubmitted** — so please double-check before opening your issue.
<br>
* Once we review the task, we will provide **feedback** as a **comment on your issue**.
