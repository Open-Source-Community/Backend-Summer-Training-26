# 📤 How to Submit Your Task

Follow these steps in order to submit your solution correctly.

---

## Steps

1️⃣ Create a **new private repository** on your GitHub account called `backend-tasks` (or similar).

2️⃣ Add the **board** and your assigned **mentor** as collaborators on the repo, so they can review your work.

3️⃣ For each session, create a file (or folder, if the task needs multiple files) named:
   `task_sessionNumber.ts`
   Example: `task_4.ts`

4️⃣ Solve the task inside that file.

5️⃣ Upload it to GitHub directly from your **browser** — you do **not** need to clone the repo.

6️⃣ To let us know you've submitted, go to **our repository** and open an **issue**:
   - **Title:** `YourName_id_sessionNumber`
   - **Body:** paste a **direct link** to your solution file (not just a link to your repo's homepage) — we should be able to click it and land straight on your solution.

---

## **NOTES:**

* Creating the `backend-tasks` repo and adding the board/mentor is **only done once** — after that, you just add a new `task_sessionNumber.ts` file for each session.
<br>

* Submissions **that don't meet these points** (wrong file naming, indirect link, or messy/unmatched steps) **will need to be resubmitted** — so please double-check before opening your issue.
<br>

* Once we review the task, we will provide **feedback** as a **comment on your issue**.
